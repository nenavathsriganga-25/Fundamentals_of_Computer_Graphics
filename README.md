# Fundamentals of Computer Graphics

This repository contains the laboratory assignments completed as part of the **Fundamentals of Computer Graphics (FOCG)** course at **IIT Palakkad**.

## Course Labs

### Lab 1 – Environment Setup

This lab focuses on setting up the development environment required for the Fundamentals of Computer Graphics course. It includes configuring OpenGL and the required libraries and tools for running graphics programs.

### Lab 2 – Basic OpenGL Rendering

This lab introduces the basics of OpenGL rendering. It covers creating a window using GLFW, writing vertex and fragment shaders using GLSL, creating VAOs and VBOs, and rendering a colored triangle.

### Lab 3 – OpenGL Primitives and Drawing

This lab focuses on drawing and managing multiple geometric objects using OpenGL. It includes rendering a rectangle using indexed drawing with an EBO and working with multiple objects and different rendering modes such as solid triangles and outlines.

### Lab 4 – 3D Cube and Transformations

This lab introduces 3D graphics and transformations using OpenGL and GLM. A 3D cube is rendered with six solid-colored faces and eight differently colored vertices. Keyboard arrow keys are used to rotate the cube in different directions using transformation matrices and GLSL uniforms.

## Technologies Used

- C++
- OpenGL
- GLFW
- GLSL (OpenGL Shading Language)
- GLM (OpenGL Mathematics)
